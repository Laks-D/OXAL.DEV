## The Site

Built as a single-file, dependency-light editorial experience. No frameworks. No build tools. Just obsessively crafted HTML, CSS, and vanilla JS — because we put our money where our mouth is.

**Highlights:**
- Lenis smooth scroll engine for buttery, premium page feel
- Custom dual-cursor system (crosshair + morphing "VIEW" cursor)
- Charcoal particle engine — ink strokes that follow your mouse
- Cinematic staggered word reveal on scroll
- Text scramble effect on section headers
- SVG sketch animation with live pulse
- 3D card tilt with `perspective()` on hover
- Kinetic percentage page loader
- Typewriter tagline engine in the hero panel
- Scroll-progress vermilion bar
- Floating editorial nav with scroll-aware show/hide
- Vermilion sweep transition on CTA clicks

**Stack:**
```
HTML5 · CSS3 (Custom Properties, Grid, Keyframes) · Vanilla JS
Lenis v1.0.42 (smooth scroll)
Google Fonts: Cormorant Garamond · Cormorant SC · Space Grotesk · Space Mono
```
